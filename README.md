# Country Language Redirect

A small JavaScript project that redirects users to the appropriate website based on their **country and language**.

## About

This is one of my early JavaScript projects as I start building and learning consistently.

The project checks:

* Visitor's country
* Visitor's preferred language
* Matching URL from the country data

Then it redirects the visitor to the corresponding URL.

## Technologies

* HTML
* CSS
* JavaScript

## How It Works

```text
Visitor Country
      ↓
Find Country
      ↓
Check Language
      ↓
Find Matching URL
      ↓
Redirect User
```
